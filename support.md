## Frequently Asked Questions

1. **Is there an Android version?** Not at this time and unlikely in near future.

2. **The app crashes when playing recordings.** This is a known issue in version 1.5, likely caused by changes to the recordings API or newer iOS versions. There is no fix date yet.

3. **When will the next release be?** There is no date yet. This is a hobby project of mine and since the app is given away it's hard to prioritize over other work.
